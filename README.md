# Networking-Labs
🌐 Hands-On Networking Lab

Welcome to the Hands-On Networking Lab repository! This project contains step-by-step guides, topologies, configurations, and practical exercises designed to demonstrate foundational and advanced networking concepts.

🚀 Overview

This repository serves as a practical environment to learn, build, and test networking protocols and architectures. Whether you are studying for networking certifications (e.g., CCNA, Network+) or exploring computer networks hands-on, these labs cover essential concepts through interactive configurations and packet analysis.

📚 Lab Topics
Module      Topic                          Key Concepts
01          Basic IPv4 & Subnetting        CIDR, Subnetting, Interface Configuration
02          Switching Basics               VLANs, Trunking (802.1Q), Inter-VLAN Routing
03          Spanning Tree Protocol         STP, RSTP, Loop Prevention
04          Static & Dynamic Routing       Static Routes, OSPF, BGP Basics
05          Network Services               DHCP, DNS, NAT/PAT
06          Packet Analysis                Wireshark Capture, TCP/IP Handshake, PCAP Analysis

🛠️ Prerequisites & Tools

To successfully complete these labs, you will need the following tools:

Cisco Packet Tracer or GNS3 / EVE-NG (for topology simulations)

Wireshark (for packet capture and analysis)

Terminal / CLI access (SSH/Telnet client like PuTTY or native terminal)

Basic understanding of the OSI and TCP/IP models
