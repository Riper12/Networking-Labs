# Lab 2 - Switch Configuration & VLANs

## Objective
Configure a Cisco switch with VLANs and verify port assignments.

## Devices
- 2 PCs
- 1 Cisco 2960 Switch

## VLANs
- VLAN 10 - SALES
- VLAN 20 - HR

## Configuration Performed
- Configured hostname
- Configured enable secret
- Configured console password
- Created VLAN 10 and VLAN 20
- Assigned switch ports to VLANs
- Saved configuration

## Verification
- show vlan brief
- show interfaces status
- show running-config

## Result
Verified VLAN creation, interface assignments, and observed that devices in different VLANs cannot communicate without inter-VLAN routing.
